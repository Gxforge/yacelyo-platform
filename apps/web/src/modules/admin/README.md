# Admin Module

Panel administrativo para YACELYO (sin código).

Funciones:
- CRUD productos y categorías
- Gestión de stock y precios
- Actualización de tasas USD/CUP en tiempo real
- Gestión de órdenes (pendiente, confirmado, enviado, entregado)
- Subida de imágenes a R2
- Reportes de ventas

Ruta: /admin (protegida con Cloudflare Access)

Stack: Next.js App Router + Drizzle + D1 + R2
