# YACELYO Web - Storefront

Aplicación Next.js 14 con App Router, optimizada para Cloudflare Pages.

## Desarrollo

pnpm install
pnpm dev

Abre http://localhost:3000

## Estructura

- src/app - Rutas (home, categoria, producto, carrito, api)
- src/components - Componentes UI y de layout
- src/modules - Lógica de dominio (catalog, cart, checkout, payment)
- src/data - Datos migrados desde mitarjeta.biz
- src/lib - Utilidades, DB, Cloudflare

## Diseño

Paleta: Negro #0a0a0a, Blanco #ffffff, Neutros #f5f5f5, Acento #9B0970
Tipografía: Inter
Inspiración: SHEIN, Zara, Apple Store - Minimal, alta conversión, sin distracciones.

Sin emojis. Tipografía con tracking amplio para look premium $10k.
